# 欧州サッカー トラッカー

欧州主要6リーグ、UEFAチャンピオンズリーグ（CL）、J1の日程を日本時間で確認する **Streamlit製Webアプリ** です。欧州の大会は試合結果と順位表も表示します。

> ポートフォリオ作品 / Python・Streamlit・外部API連携

## 主な機能

- **日程・結果**：リーグごとに試合日程、キックオフ時刻、クラブ名・エンブレム、取得可能な試合結果を表示
- **欧州国内リーグ**：節ごとの前後移動と選択。初回表示は現在に近い節を自動で選択
- **CL・J1**：月単位で日程を移動・選択
- **一括表示**：複数大会を期間または共通の節で絞り込み
- **順位表**：欧州6リーグおよびCLの取得可能な順位表。PCでは詳細列、スマートフォンでは主要5列を表示
- **レスポンシブ表示**：スマートフォン向けの試合カード・順位表
- **データのキャッシュ**：APIへの重複アクセスを削減

## 対応大会・データソース

| 大会 | 日程 | 結果 | 順位表 | 取得元 |
|---|---|---|---|---|
| プレミアリーグ / ラ・リーガ / セリエA | ○ | ○ | ○ | football-data.org |
| ブンデスリーガ / リーグアン / エールディヴィジ | ○ | ○ | ○ | football-data.org |
| UEFAチャンピオンズリーグ | ○ | ○ | 取得元で利用可能な場合 | football-data.org |
| J1 | ○ | — | — | Jリーグ公式クラブカレンダー |

※ J1は日程のみ。結果や順位は[公式サイト](https://www.jleague.jp/)で確認してください。football-data.org無料枠では配信内容・更新タイミングに制約があります。大会によってデータが存在しない期間があります。

## 使用技術

- Python 3
- Streamlit
- requests
- icalendar（J1公式カレンダーの読み取り）
- HTML / CSS（表示調整）
- `st.cache_data`（API結果のキャッシュ）

## ローカルでの起動

1. Pythonをインストール
2. 必要なパッケージをインストール

   ```bash
   pip install streamlit requests icalendar
   ```

3. プロジェクト内の `.streamlit/secrets.toml` を作成（公開しないこと）

   ```toml
   FOOTBALL_DATA_API_KEY = "YOUR_API_KEY"
   ```

   もしくは同名の環境変数を設定してください。

4. アプリを起動

   ```bash
   streamlit run footballapp.py
   ```

   このREADMEと一緒に配布する `footballapp_v1_improved.py` を使う場合は、`footballapp.py` にリネームするか、起動対象をそのファイル名に変更してください。

## 設計上の工夫

- 日本時間で日付と時刻を統一して表示
- 国内リーグは1シーズン分の試合情報を取得し、節切り替えは取得済みデータから絞り込む方式
- J1はクラブ別公式カレンダーを取得して重複試合を統合
- APIキーをソースコードに埋め込まず、Streamlit Secretsまたは環境変数で管理
- APIエラーやデータ欠損時には、ページ全体を停止せずに案内を表示
- 表示するクラブ名や外部URLをHTML出力前に検証・エスケープ
